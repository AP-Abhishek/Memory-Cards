# Memory Cards

## Memory Cards is a simple memory game, in which the player has to remember the cards which he/she clicked and then match it with the other card. If both cards matches, then both the card will be kept facing front, else the cards will be rotated back and the game continues. Once all the cards are facing front the game is over. This helps the user to memorize things and make his/her brain sharp.

## Tools used:
1. Python
2. pygame
